# homekit-cli

Control and inspect Apple HomeKit from the terminal, MCP clients, and agent workflows.

This package provides the `homekit` binary:

```bash
npx homekit-cli status
npx homekit-cli bridge setup
npx homekit-cli --mcp
```

For full documentation, architecture, supported accessories, setup, development, and release notes, see the project README:

https://github.com/l3wi/homekit-cli
